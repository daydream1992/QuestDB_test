d2 极端	0.15	100·(0.6·norm(zt)+0.4·(1-norm(dt)))	涨停1080 / 跌停540	涨停74·跌停4	94.9

几个值得注意的细节
d5 封板质量 = 0:封成比 0.28 < 归一化下限 0.3 → 截断 0。所以日志里 "封板质量差(封成比<0.3)" 的结论和 d5 得 0 分是同一件事
d1 广度只有 25 分:udr 1.13 离 3.0 上限很远 → "涨幅集中,非普涨" 正是 d1 低分的体现
d3=100 反推:由综合分逆推 loss_ratio ≤0.5,即涨超5%家数远多于跌超5%,偏暖日的典型分布
区间截断是双刃:d8 sector_zt=52 超出 30 上限直接打满,量纲在区间外不区分(52 和 30 都得 100)
_label(score) 档位门限:≥80 高潮 / ≥60 偏暖 / ≥40 中性 / <40 冰点 → 63.0 落"偏暖"。
